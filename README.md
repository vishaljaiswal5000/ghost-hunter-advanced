# Ghost Hunter Game 
 
 Created on Unity 
 
 Reanimation of pac man

## Play / deploy on itch.io

Controls: WASD / arrow keys, or swipe on touch screens (phones, tablets). Pick Level 1 or Level 2 on the start screen.

Build (Unity 6000.6.4f1 with the WebGL module installed): **Build > WebGL (itch.io)**.
Output goes to `Builds/WebGL`. Zip the *contents* of that folder (so `index.html` is at the
root of the zip) and upload it to itch.io as "This file will be played in the browser".
Suggested embed size: 1280 x 720. On the itch.io page enable "Mobile friendly" (and "Fullscreen button") so
phones launch the game full-screen; the camera adapts to portrait and landscape.
